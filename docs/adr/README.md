# Architecture Decision Records

## What is an ADR?

An Architecture Decision Record (ADR) captures an important architectural decision made along with its context and consequences.

## Why ADRs?

- Document the reasoning behind important decisions
- Provide context for future developers and agents
- Create a searchable history of architectural choices
- Enable informed decision reversal when needed

## ADR Process

1. Copy `ADR_TEMPLATE.md`
2. Number sequentially (0001, 0002, etc.)
3. Fill in all sections
4. Commit with the implementation

## ADR Format

See `ADR_TEMPLATE.md` for the standard format.
